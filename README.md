# Fragment: моды и Sky Art Study

Minecraft 1.21.1, NeoForge 21.1.262.

Скачайте всю ветку: Code → Download ZIP, распакуйте. Запустите assemble-render.bat (Windows) или sh assemble-render.sh (Linux/macOS). Скрипт объединяет три части Render и извлекает его JAR в mods.

Перенесите mods, saves, lod-packages в папку игры. Удалите старые дубли модов. Отдельный Modern UI не нужен. Ресурспак NatureX устанавливается отдельно.

Войдите в Sky Art Study и выполните `/voxy mesh load sky-linked-parent -1`.

Vision: 4e1b18cc; Render: 4ee395b; Grass: 52770fd. Это WIP.
