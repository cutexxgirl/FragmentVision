# Вторая итерация: грунт под лесом и материалы склонов

Первая версия 6930355f визуально не принята: отдельные сглаженные вершины,
кубические холмы и снег, протянутый вниз по камню. Старые before.png / after.png
сохранены для истории, это не изображения текущей итерации.

Исправленные причины:

- Кроны и стволы больше не заканчивают поиск земли. Высота берётся из настоящего
  грунта под ними. Геометрия самих деревьев остаётся прежней.
- Область увеличена с 768 до 1088 блоков: при текущей дальности Vision 512 блоков
  граница снимка больше не обрезает дальние горы. Для других больших дальностей
  ещё нужна автоматическая система плиток.
- Шаг сетки уменьшен с 4 до 2 блоков; коррекция высоты ограничена 0.6 блока.
  Граница воды/неизвестных блоков защищается одним соседним образцом.
  Вокруг каждого дерева больше нет отдельной широкой дыры.
- Рыхлый снег включён в грунт наряду с обычным снегом и снежными слоями.
- Отдельно читаются покрытие и блок на 3 блока ниже. На крутом склоне доля
  покрытия уменьшается. Дополнительно во время сборки временно сохраняются
  столбцы материалов из кэша: длинные треугольники склонов разделяются и получают
  породу на фактической высоте промежуточных точек. Поиск идёт внутрь склона вдоль
  нормали, с запасным материалом под покрытием. Временный объём существует только
  на CPU при сборке; 3D-текстуры и raymarch в кадре нет. Это приближение к исходным
  граням, поскольку геометрия всё ещё heightfield.
- До шести материалов на треугольник смешиваются по весам вершин; исчез выбор
  единственного материала для всей ячейки. Однородная поверхность использует
  одну выборку текстуры. В худшем случае смешиваются шесть выборок.
- Биомный цвет применяется только к текстурам с tint. Камень и снег им не
  окрашиваются. Масштаб текстуры теперь один повтор на блок.
- Освещение воздуха непосредственно над грунтом читается из кэша, вместо
  постоянного полного skylight. Под лесом это сохраняет затенение от крон.
- Замыкающие края сокращены с 8 до 2 блоков и используют подповерхностный
  материал. Это временная сшивка; не гарантия отсутствия всех щелей.

Ограничения остаются: heightfield не воспроизводит навесы и пещеры, исходные
деревья кубические, обычные чанки сохраняют блоки, область native+48 блоков
защищена. При перемещении камеры нужен повторный build. Исходные terrain quads
всё ещё отправляются GPU и маскируются фрагментным шейдером. Увеличение плотности
этой экспериментальной сетки не является оптимизацией; FPS на аппаратной GPU
не измерен. Семантика построек из естественных материалов пока не решена.

Управление остаётся /voxy hybrid build, /voxy hybrid on, /voxy hybrid off.
По умолчанию выключено. Общие свет/облака/вода и стабильные ветки не менялись.
