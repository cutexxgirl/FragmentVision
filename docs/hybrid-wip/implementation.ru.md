# Hybrid terrain WIP: открытый рельеф поверх кэша Vision

Экспериментальная ветка wip/hybrid-terrain основана на render-atmosphere
9a6e51b8. Сопутствующая ветка Fragment Render с тем же именем добавляет только
необязательный вход интерполированной нормали FR_HYBRID_SURFACE. Обычные
материалы и стабильные ветки этим экспериментом не заменяются.

## Что реализовано

По /voxy hybrid build один фоновый поток читает существующие WorldSection
уровня0. Получаем внешний рельеф квадрата768×768 блоков с шагом4. Это реальные
сохранённые блоки; сид, генератор и повторная генерация мира не используются.
WorldEngine удерживается ссылкой до завершения чтения. Работа не запускается
каждый кадр. Меш хранится только в памяти, формат базы Vision не меняется.

Первый прототип намеренно ограничен внешней поверхностью. Верхние точки
естественного грунта соединяются треугольниками; ограниченная корректировка
высот (не более1.5 блока) убирает небольшие изломы. Нормали вычисляются по
соседним высотам. Снег/камень/трава и другие разрешённые поверхности берут
текстуры из реально активного РП. Биомный tint использует существующий
ModelFactory/Fragment bridge, а не отдельную захардкоженную зелёную палитру.

Текстуры находятся в небольшом массиве32×32 с mip-уровнями. Масштаб — один
повтор на4 блока, а не растяжение спрайта на всю гору. На крутых участках
выбирается проекция по главной оси нормали: одна выборка цвета вместо трёх
выборок полного triplanar. Возможны видимые стыки проекций и границы материалов.

В обычной геометрии модели естественного грунта помечаются runtime-битом8;
маркер включён в ключ дедупликации. Деревья, жидкости и остальные модели не
маскируются. Вокруг отснятых деревьев/воды/неизвестных поверхностей сохраняется
запас8+ блоков. Области без образцов остаются на кубическом пути. Квадрат
обычных чанков плюс48 блоков исключён до построения меша, с дополнительным
запасом от проверки соседей. Это проверка mountains-only, не новая система леса.

Маска ячеек общая для оригинальных граней и поверхности. Первый пробный
screen-door переход дал постоянную рябь и отклонён. Финальный WIP использует
непрозрачные границы и опущенные на8 блоков края для закрытия стыков. Более
глубокие24-блочные края давали заметные белые «занавески» на снегу и отклонены. Сложные
перепады крупного LOD всё ещё могут выдавать шов; это не универсальная сшивка
адаптивных объёмных сеток.

Новая поверхность рисуется в существующий opaque target Vision перед SSAO,
затем проходит тот же composite с атмосферой Render. Принимает прежний
свет солнца/неба, облачные тени и доступную карту теней настоящих чанков.
Нового дальнего shadow caster pass нет. За радиусом карты нет настоящих
теней от всех дальних гор и деревьев; это ограничение не скрывается.

## Управление и обновления

Эксперимент выключен по умолчанию и не записывается в пользовательские настройки.

* /voxy hybrid build — подготовить ограниченную область вокруг текущей камеры.
* /voxy hybrid on / off — включить либо вернуть исходную геометрию без пересборки.
* /voxy hybrid — состояние и число треугольников/время подготовки.

Изменения кэша вне защищённой ближней зоны инвалидируют снимок. Фоновые обновления
настоящих чанков внутри этой зоны не сбрасывают меш, который там не используется.
При перемещении камеры более8 блоков по XZ либо смене native render distance
WIP возвращается к кубикам и просит build. Нужны автоматические плитки, очередь
обновлений и более локальная инвалидация для обычной игры. При закрытии мира
worker останавливается, GL-ресурсы освобождаются. При ошибке подготовки — fallback.
Прототип требует материал Fragment Render; отдельный Vision сохраняет обычный путь.

## Границы достоверности и производительности

Это heightfield-пилот: арки, навесы, входы в пещеры и многоуровневую поверхность
он корректно не реконструирует. Для полной версии нужен объёмный mesher либо
надёжное исключение таких областей. Узкие объекты между точками сетки могут
не попасть в маску защиты. Постройки из тех же камня/земли, что входят в allowlist,
невозможно безошибочно определить по одному block ID. Пока нет отдельного
семантического слоя строительства: нельзя обещать сохранение всех построек.

Сейчас исходные terrain quads всё ещё отправляются GPU и скрываются во fragment
shader там, где готова новая поверхность. Добавлены один draw меша и маска покрытия;
это проверка геометрии и внешнего вида, не готовая оптимизация FPS. Чтобы получить
выигрыш, нужно исключить заменённые грани до отправки и согласовать occlusion
иерархии Vision с новым рельефом. Деревья остаются существующими Voxy LOD.
Аппаратного GPU в окружении нет: llvmpipe не позволяет обещать игровой FPS.

Проверки: сборка Vision, standalone CPU checks плоскости/нормалей/защитных
областей/пропущенного кэша, компиляция настоящих6 shader variants (с материалом
и без него, opaque/translucent, surface normal/reverse depth), реальный Minecraft
и исходные F2 из одной сцены. Исходники Ecstatic не копировались.
