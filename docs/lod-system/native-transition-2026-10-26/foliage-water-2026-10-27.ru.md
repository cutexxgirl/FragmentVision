# Листва и вода: проверка в Sky_Art_Study, 27 октября

## Результат и границы

Исправлена потеря двусторонних quad-поверхностей при отрисовке baked backend.
Пакет `sky-joined-selected`, источник мира и политика удаления растений не менялись.
Листва сохранена, мелкая трава/цветы по-прежнему исключаются. Плавного native collar
в runtime ещё нет: README в этой папке — контракт, NativeTransitionField — CPU reference.

## Воспроизведение

Камера 448,180,800, yaw 90, pitch 10, FOV 50, день 4500, fixed L2.
Оригинальный fragment shader + mixed MDI: голые стволы.
Тот же shader и геометрия + прямые instanced draws: кроны на месте.
Только переход с SSBO на divisor-атрибуты при прежнем mixed MDI проблему НЕ решает.
Шесть directional opaque-команд через MDI и отдельный direct draw двустороннего
хвоста восстанавливают листву и воду в самом клиенте. Низкоуровневая причина
разницы с EGL ещё не установлена; это проверенный обход сбоя, не доказанный
универсальный дефект драйвера. Нельзя считать синтетический тест заменой кадру.

Продуктовый код использует обычный integer instance attribute для тех же 8 байт
quad. Пересортировка, размеры буферов, число экземпляров/треугольников не меняются.
Финальный обход: удалить нулевые команды из активного префикса каждой страницы,
передать фактический drawCount. Зарезервированное место командного буфера и offsets
сохраняются; хвост обнуляется, но в drawCount не входит. Один MDI вызов на страницу,
те же видимые directional buckets, те же экземпляры, никакого роста треугольников.
По умолчанию submission=3; режимы 0/1/2 оставлены для точного A/B. Причина, почему
нулевые slots ломаются только в полном клиенте, пока не установлена. EGL варианты
проходят и с ними; не объявлять это универсальным дефектом API/драйверов.
На software GL нельзя делать вывод о FPS GPU.

Отдельно исправлен срок жизни кэша uniform locations Fragment Render: после
удаления/перелинковки GL program старые locations сбрасываются. Иначе при reload
повторно использованный program ID приводил к GL_INVALID_OPERATION. Расширение
bridge опционально, со старым Render остаётся no-op.

## Проверки

- Gradle build Vision; клиент Render с новым jar.
- Компиляция 12 shader-вариантов, включая reverse Z, compact и packed.
- GPU layout, surface material и quad indirect проверки.
- Реальный material shader: opaque/alpha-cutout leaves/water/snow, большие
  baseInstance, нулевые команды, direct/MDI/split tail совпадают в EGL.
- NativeTransitionFieldCheck: прямой край, объединение границ, внутренний угол
  справа+снизу, выпуклый угол, отрицательные координаты, непрерывная производная.

## Дополнительная проверка automatic levels

В automatic режиме split tail вернул кроны, но обнаружились голубые полосы
на L0 склоне. Переключение `/voxy mesh submission 1` (прямые directional
buckets) устранило и эти пропуски. Это ещё один submission-дефект, его нельзя
выдавать за исправленный native collar. Доступны A/B режимы 0 split, 1 direct,
2 original mixed MDI, 3 compact nonempty MDI. Сравнивать на одном пакете/камере.

**Финальная проверка:** mode 3 сжатого префикса также убрал голубые полосы и
сохранил кроны в automatic режиме. Он выбран по умолчанию. Контрольный кадр
2026-10-27_11.49.41.png, чистый кадр и сравнения приложены в images/.

## Что ещё не исправлено

Жёсткий native→LOD стык, снег/камень в грубых треугольниках, внешний квадратный
край ограниченного тестового пакета, отсутствие streaming/edit ownership. Вода
LOD сейчас непрозрачная дальняя поверхность с освещением Fragment Render;
детальная native вода сохраняет свой проход. Не объявлять весь backend готовым.
