# Native → near LOD: действующий переход и причина цветового шва

## Что внедрено

В `BakedMeshBackend` подключена настоящая переходная геометрия. Это первый
native → near L0 collar, а не морф двух независимых QEM-мешей всех дальних уровней.
Первые 2 блока снаружи native сохраняют исходные целочисленные ступени; следующие
12 блоков постепенно переходят в скруглённую сетку с той же топологией. Смещение
ограничено примерно 0,35 блока. Дальше L1/L2 выбираются прежним projected-error
policy; их существующие контуры страниц остаются закреплёнными.

Граница строится из действительно построенных exterior-секций Sodium. Берём
консервативное объединение: если готова хотя бы одна секция поверхности в колонке,
сохраняем точную форму всей колонки. Требование готовности всех высот ошибочно
исключало обрывы с ещё не построенными скрытыми нижними секциями. Дальность камеры
используется только для ограничения поиска, а не вместо проверки готовности.

Прямой край и внутренний угол справа+снизу используют одно мировое поле весов:
объединённые внешние отрезки ready-ячеек, quintic smoothstep и произведение влияний.
Поле имеет пространственный кэш; GPU получает две небольшие R32F-карты. При
изменении ready-состава предыдущая карта берётся из **текущего интерполированного
состояния**. На освобождение отводится 150 мс, предыдущая полоса удерживается до
завершения перехода. Новая точная зона закрепляется до показа поверх native.
Готовность проверяется каждый кадр; карты пересчитываются только при изменении.

Стороны страниц, открытые края пещер и контакты со снегом, водой, стволами и
постройками закреплены. Переходная страница заменяет соответствующую L0-страницу,
а не рисуется вторым слоем поверх неё. UV остаются мировыми, atlas исходный,
усреднения текстур и дополнительного размытия нет. В точной зоне восстанавливается
исходная гранёная нормаль; дальше включается нормаль скруглённой поверхности.

## Цвет: что проверено на самом деле

1. Сверены RGB нативного `BlockColors`/Fragment palette с `ModelFactory` и
   **биомами из загруженных LOD-файлов**, а не только с предполагаемым биомом мира.
   На поверхности и реальных листьях проверены 363 значения: 359 совпали точно,
   оставшиеся 4 отличаются не более чем на 3/255 у границы meadow. Высоты исходной
   поверхности совпали во всех точках (79–128), пропущенных samples нет.
   [Полная таблица](colour-audit.tsv).
2. В 10 строках отличаются названия лесных биомов (old_growth_birch_forest /
   birch_forest / dark_forest), но их Fragment family и RGB одинаковы. Это не причина
   обнаруженного холодного шва. Палитру ради компенсации не перекрашивали.
3. Проверены пути материалов: общий atlas и общие функции High lighting, одинаковые
   параметры солнца/неба/теней. Native AO и canopy-нормали отличаются от дальних
   полноразмерных кубов; это влияет на локальную форму освещения, не доказывает
   ошибку базовой биомной окраски. Режим `frleaf materials` без air проверен в мире.
4. Найдена и исправлена **повторная атмосфера**: baked fragment применял air/edge,
   а `NormalRenderPipeline.finish` применял их ещё раз. Комментарий о якобы
   пропущенном composite был неверным. Теперь baked material отдаёт цвет без air,
   общий финальный проход добавляет его один раз, как у остальных LOD.
5. GPU regression теперь выполняет оба реальных прохода — material и final blit.
   До исправления тест давал `[0.4375, 0.25, 0.25]` вместо `[0.625, 0.5, 0.5]`;
   после исправления проходит для ordinary/snow/water. Старый тест проверял только
   первый проход и потому пропускал эту ошибку.
6. Обычный vanilla terrain fog уже отключается `MixinFogRenderer` при активном
   Vision; добавлять ещё один обход или менять дальность тумана не понадобилось.
   SMAA применяется к итоговому кадру, временного накопления здесь нет; изменение
   насыщенности или mip bias не использовалось для сокрытия цветового шва.

Важное различие: одинаковые исходные RGB не требуют одинаковых экранных RGB у
разных деревьев, нормалей и расстояний. Проверялся источник скачка, а не совпадение
цвета разных объектов на глаз. Холодная воздушная перспектива вдали сохраняется,
но больше не удваивается на границе backend.

## Проверки и кадры

- Gradle build; 14 shader-вариантов, включая collar и reverse Z.
- GPU-проверка fine/target, мирового адресования весов, exact/growth clamp и release.
- [Геометрический аудит](geometry-audit.txt): 1024 страницы, 2 627 671 треугольник;
  все 8 сочетаний source/target трёх вершин сохраняют знак проекции площади.
  Площадь multi-affine по весам, поэтому проверены все промежуточные веса, а не
  только два крайних кадра. Общие контуры страниц точны. Максимальная компонента
  смещения после 1/256 quantization — 0,3515625 блока.
- В мире Sky_Art_Study проверены исходный ракурс, переключение join off/on,
  движение вперёд и затем по перпендикулярной оси. Проверены логи GL.

## Стоимость и границы WIP

Пакет `sky-native-join-v3` сохраняет исходный `sky-joined-selected` и добавляет
1024 sidecar-страницы на всю его область. Около 27 МБ на диске; счётчик resident
GPU-буферов вырос с 86,23 до 124,32 МБ. Карты весов добавляют `width*height*8` байт
GPU плюс две CPU-копии. Это **не бесплатный переход** и не новый выигрыш над Voxy.
Треугольники sidecar не рисуются одновременно с заменённой L0-страницей. В кадре
активна только near-полоса; точная часть внутри native отсечена существующим
stencil. Сохранён один draw на mesh-страницу; QEM/сглаживание на кадре не запускаются.

Это ещё не полный linked morph L0→L1→L2, не streaming готового продукта и не
инвалидация offline-кэша после редактирования мира. Эти ограничения прежнего WIP
не объявляются решёнными этим переходом. Дальний край ограниченного пакета и
стоимость сохранённых деревьев/старой резервной Voxy arena остаются отдельной работой.

## Воспроизведение

Исходники: Vision `wip/lod-surfaces-and-water`, Render `wip/hybrid-terrain`.
Рабочий профиль: `fragmentrender-sky/run-water`, мир `Sky_Art_Study`.
Пакет: `/voxy mesh load sky-native-join-v3` (автоматические уровни).
`/voxy mesh join false|true` меняет только подключение collar/near policy.
`/voxy mesh colours` пишет аудит в `lod-colour-audit.tsv`.
`/frleaf materials`, `/frleaf air_off`, затем `/frleaf normal`, `/frleaf air_on` —
dev-only диагностика Render. Фиксированный `/voxy mesh load ... 2` намеренно
не включает native collar: этот режим используется для отдельных сравнений.

Offline bake выполняется только из сохранённых batch snapshots:

```sh
JAVA_HOME=/path/to/jdk21 python tools/lod/build_native_collars.py BASE_PACKAGE SNAPSHOTS COLLARS
python tools/lod/install_native_collars.py BASE_PACKAGE COLLARS NEW_PACKAGE
```

Installer сохраняет исходный пакет, проверяет palette/source binding и хэши.
Loader ограничивает число страниц, bytes и GPU storage, проверяет привязку к L0.
Стандартные страницы без sidecars остаются совместимыми.
